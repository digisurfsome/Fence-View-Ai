System Overview

Welcome to the Brain Administration System. This is your control center for creating personalized, adaptive marketing experiences. The system has two main parts:

Admin Panel (Backend)

Where you build and configure Talk Flows, questions, actions, and split tests. This is where you control the "brain."

Frontend Pages

What users see - landing pages, share pages, etc. These read your configurations and display the personalized experience.

The Big Picture

You create Talk Flows in the admin panel. A Talk Flow is a sequence of questions, conversations, and actions. You can then connect that Talk Flow to any page (fencing, roofing, share page, etc.).

Understanding Talk Flows

A Talk Flow is the sequence of interactions a user goes through. Think of it as a conversation script that adapts based on their answers.

Example Talk Flow
Intro
→
Question 1
→
Text
→
Question 2
→
Action
→
Result

Talk Flow Components

Intro Frame

Sets context before questions start. "Help us find your perfect match..." Makes questions feel natural, not like profiling.

Questions

Each has 4 options mapping to personality types (D, I, S, C). Can be adaptive - phrasing changes based on previous answers.

Text Steps

Conversation between questions. "Great choice! That tells us a lot..." Levels: Light, Medium, Heavy.

Actions

Things that happen: Share for votes, show results, collect info, trigger AI response. Placed anywhere in flow.

The DISC Personality System

Every answer maps to one of four personality types:

Code Type What They Want How AI Talks to Them
D Direct Speed, results, efficiency "Let's get this done. Bottom line..."
I Influencer Looks, social proof, compliments "This is going to look AMAZING!"
S Steady Family, safety, peace of mind "Your family will feel so safe."
C Conscientious Quality, data, best value "Here's the data... The ROI is..."

Using the Quiz Builder

Open Quiz Builder →

The Quiz Builder has 7 tabs. Here's what each does:

Tab 1: Flow Builder

What It Does

Shows your complete Talk Flow visually. Add, remove, and reorder components. This is your "bird's eye view."

  • Visual Flow: See Intro → Q1 → Text → Q2 → Action → Result
  • Sequence List: Reorder with ↑↓ buttons, remove with ×
  • Quick Add: Buttons to add Questions, Text, or Actions

Tab 2: Questions

What It Does

Create and edit all your questions. Each question has 4 options that map to personality codes.

  • Add Question: Creates new question with default options
  • Question Text: The actual question users see
  • Adaptive Toggle: When ON, shows variation fields
  • Variations: Different phrasings based on previous answer (D/I/S/C)
  • Options: 4 answers, each with text and personality code

Tab 3: Steps (Text/Actions)

What It Does

Manage what happens BETWEEN questions. Text steps are conversations. Action steps trigger behaviors.

  • Text Steps: Conversation content + level (light/medium/heavy)
  • Action Steps: Shows actions from library, add/remove from flow

Tab 4: Actions Library

What It Does

Define reusable actions. Actions are THINGS THAT HAPPEN - share, collect info, show results, etc.

Action Type What It Does
share_vote User shares link to friends for voting
show_results Display fence/roof transformation results
collect_input Gather email, name, phone, etc.
show_social_proof Display testimonials or vote counts
trigger_ai AI responds in their personality style
custom Define your own with JSON config

Tab 5: Personality Types

What It Does

Configure how the AI communicates with each personality type AFTER profiling is complete.

  • Tone Guidelines: Instructions for how to speak to them
  • Example Phrases: Actual phrases the AI should use

Tab 6: Split Testing

What It Does

Configure what variables the brain should test to find optimal conversions.

  • Question Count: Test showing 2, 3, 4, or 5 questions
  • Conversation Level: None vs light vs medium vs heavy
  • Action Placement: When to trigger actions
  • URL Generator: Creates test URLs for each variant

Tab 7: Preview

What It Does

Test your Talk Flow as users will experience it. Select different configurations.

Current Storage Method: localStorage

Right now, configs are saved to your browser's localStorage under the key quiz_config_v2. All pages on the same domain can read this.

Important

localStorage is per-browser. If you configure on your laptop, your phone won't have the same config. For production, we'll move to a database/API.

Export/Import for Sharing

To share configs across devices or backup your work:

Export

In Quiz Builder, click "Export JSON" - downloads quiz_config.json

Transfer

Send the JSON file to another device or save as backup

Import

On the new device, click "Import JSON" and select the file

Actions In-Depth

Actions are the THINGS THAT HAPPEN during a Talk Flow. They're not questions or text - they're interactive moments.

Action Configuration

Each action has these fields:

Field What It's For
ID Unique identifier (auto-generated)
Type What kind of action (share_vote, collect_input, etc.)
Title Internal name for your reference
Description What this action does (for your reference)
Button Text What users see on the button
Config (JSON) Action-specific settings

Creating Custom Actions

Select type "custom" and use the JSON config to define behavior:

{
  "trigger": "on_click",
  "behavior": "open_modal",
  "modalContent": "custom_form",
  "fields": ["email", "phone"],
  "onSuccess": "next_step"
}

Split Testing

The brain learns by testing different variations and seeing what converts best. Here's what you can test:

Question Count

Do 2 questions convert better than 5? Test ranges from min to max.

Conversation Level

Rapid-fire questions vs. lots of talking between. Which builds more trust?

Action Placement

Share after Q1? After Q2? After all questions? Test to find optimal moment.

Intro Frame

Does showing context before questions help or hurt?

Using Test URLs

The Split Testing tab generates URLs like:

/fencing/?questions=3&conv=light&action=after_q2

These parameters tell the page exactly which variant to show. Send different URLs to different traffic sources to compare.

Quick Start Guide

Get up and running in 5 minutes:

Open Quiz Builder

Go to /admin/quiz-builder.html

Review Default Flow

The Flow Builder tab shows a pre-built flow: Intro → Q1 → Text → Q2 → Q3 → Action → Result

Customize Questions

Go to Questions tab, edit the question text and options to match your industry/voice

Set Personality Tones

Go to Personality Types tab, customize how the AI talks to each type

Preview

Go to Preview tab, click "Start Preview" and test the flow

Save

Click "Save All Settings" at the bottom - config saved to localStorage

Test Live

Open your frontend page (/fencing/) - it reads the config you just saved

You're Ready!

Start simple, test often, let the data guide you. The brain gets smarter with every interaction.
